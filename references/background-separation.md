# 文字・ラベルを背景から分離する

採用画像のPowerPoint化で、写真・質感と編集対象が重なっている場合に読む。既存の背景原本やローカルの正式素材があれば、それを再利用する。編集可能なスライドを作るために、毎回背景を生成し直す必要はない。

## 何を残し、何を別部品にするか

| 要素 | 背景側の扱い | PowerPoint側の扱い |
| --- | --- | --- |
| 写真・イラスト・色調・ぼかし | 必要に応じて一体の背景画像で保持 | 独立した画像として配置 |
| タイトル・説明・数値・注記 | 除去する | 正しい原稿からテキストを再構築 |
| ラベルの塗り・枠・影と文字 | 編集対象ならすべて除去する | 図形とテキストで再構築しグループ化 |
| ロゴ・アイコン・線・矢印 | 独立編集する対象なら除去する | 正式素材または独立部品を配置 |
| 固定で一体使用する帯・装飾 | 文字を含めず、一体の素材にできる | 他の要素と独立した背景部品として配置 |

## 分離と補完の手順

1. 採用画像と[部品一覧](parts-record.md)から、残す要素と除去する編集対象を特定する。矩形の範囲は所在地であり、透明な切り抜き境界ではない。
2. 原本があれば再利用する。なければ対象画像を実際に添付し、利用できる画像編集・生成ツールで必要な背景を補完する。
3. 文字だけでなく、後で再構築するラベルの面・枠・影も取り除く。文字と重なった装飾を矩形のまま切り抜かない。
4. 隠れた背景は周囲の写真・光・色へつながるように補完する。単色の矩形で覆ったり、文字の残像をぼかしたりして済ませない。
5. 同じサイズで比較し、被写体の形・位置・数、色調、ぼけ、余白、切り取り範囲を確認する。新しい物体や不要な装飾が増えていれば修正する。
6. 編集対象が残っていない背景へ、独立した文字・図形を重ねる。部品を動かしたときに残像や二重の文字が現れないことを検証する。

## 背景補完の指示ひな型

```text
対象画像：実際に添付した採用画像と、背景にする範囲
残すもの：被写体・位置・形・数・遠近感・照明・色調・ぼけ・余白
取り除くもの：部品IDと、文字・ラベルの塗り・枠・影などの具体的な対象
補完：隠れていた背景を周囲の写真と光の流れへ自然につなぐ
出力：元と同じ比率・切り取り範囲の背景画像。除去対象を再追加しない
```

例として、右側に機械と箱、左側に淡い余白、下部にラベルがある画像なら、機械・箱・搬送ラインと余白を保持し、見出し・説明・ラベル本体を取り除く。実案件の対象に置き換え、例の写真・文章・色を流用しない。

写真と色調・ぼかし・グラデーションが一体なら一枚で残してよい。無理に全背景を透明化しない。透過素材の生成が崩れる場合は、固定背景帯と一体にする方法も検討し、編集範囲を明示する。

文字を含む完成スライド全体を背面に残して、その上へ同じ文字を重ねない。背景だけの画像、編集可能な文字、編集可能なラベル図形として組み立てる。生成できない・除去が不完全な場合は制約を記録し、分離済みとしない。
