# 制作記録の引継ぎ

案件の情報を一か所で管理し、各工程で増えた決定と結果だけを記録します。すべてを最初から埋める必要はありません。

| 記録 | 作成する時点 | 次へ渡す情報 |
| --- | --- | --- |
| [案件情報](request.md) | 受付時、以後更新 | 正本・条件・対象・現在の工程・各記録の参照先 |
| [構成](diagram-plan.md) | 画像の構成を決めるとき | 原稿の配置先、型、接続、変更範囲 |
| [画像指示・出力記録](image-request.md) | 生成前／生成・提示後 | 実際の入力、出力寸法、採用画像と採用根拠 |
| [部品](parts-record.md) | 採用後のPPT再構成時 | 編集単位、正しい内容、形状、接続、素材判断 |
| [検証・納品](verification.md) | PPTX作成後 | 検証した版・実施結果・残存制約・納品先 |

参照先にはファイル・版・ページや項目の位置を付け、AIが実際に読み取れる状態にします。参照できない場合は必要な内容を渡します。画像生成ツール向け指示は原稿と設定を具体的に展開し、制作記録への参照だけで代用しません。

採用画像から開始する場合、未実施の構成・生成記録を作り直す必要はありません。案件情報に採用画像と根拠を記録し、必要な原稿・条件から部品化へ進みます。画像のみで完了する案件にはPPT用記録は不要です。

[工程ごとの証拠](checkpoints.md)を既存の記録から参照できるようにする。対象ページ・版・実際の操作・結果を対応させ、案件情報が古い「未着手」のままにならないよう更新する。スキル更新後も過去の案件の使用コミットは書き換えず、次回制作で使う顧客設定の参照版と区別する。
