# 案件情報・進行記録

ユーザーの依頼からAIが整理します。全欄への回答を求めず、次の工程に必要な不足だけ確認します。既存の原稿・資料はファイルと該当箇所を参照し、全文を重複保存しません。

```
案件名：
キット：顧客ID・対応世代・デザイン種別・個別設定版（認証コードの値は記録しない）
共通手順：GitHubのリポジトリ・選択ref・解決コミット・runtime-lock.json
目的・読み手・用途：
対象ページ・希望枚数・ページ構成：基本枠のID／本文の部品構成／個別設計
情報量：ビジュアル優先／中程度の情報量／詳細／超詳細（資料全体の基本値・ページ別の変更）
納品形式・編集したい範囲：

原稿の正本：ファイル・版・ページ／段落（会話原稿なら該当発言）
必須内容・数値・出典・条件：正本内の位置／追加指定
構成・WF：参照先／配置まで再現・関係のみ採用／固定箇所
使用必須の素材・参考：参照先／取り入れる特徴
個別指定：文字・配色・配置・装飾など、キットからの変更分のみ
内容の変更・要約・分割の可否：依頼に基づく範囲
確認方法：通常は画像提示後に採用確認／別指示があれば対象と指示

進行状況：現在の工程・対象ページ
構成記録：参照先
画像生成記録：参照先
採用画像：ページごとのファイル・版／採用の指示
部品記録・検証記録：作成済みの参照先
未解決事項・次の作業：
```

案件入力はこのひな型に統一します。キャンバス・文字サイズ・配置パターンなどの既定値は、デザインシステムを参照し、案件ごとには変更分だけ記録します。
