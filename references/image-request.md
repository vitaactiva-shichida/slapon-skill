# 画像生成指示と出力記録

生成ツールへ送る本文です。案件情報と構成記録から今回のページに必要な内容を具体化します。ファイル参照や型IDだけで済ませず、ツールが読むべき文章と設定をこの指示に含めます。

```
対象：ページ番号／主題／ページ種別・配置ID／新規生成または修正
成果物：文字・図解・背景を含むスライド全体の画像

掲載する正式原稿：
［このページの文章・数値・固有名詞・条件・出典を具体的に記載］
配置と関係：
［各領域に入れる内容、読み順、接続の意味、WFに従う範囲］

画像サイズ：縦横比／希望する幅W・高さH px
参照キャンバス：［顧客定義の幅 × 高さと単位。Standardは1600×900参照px］
換算：文字の参照値 × W ÷ 同じ参照単位のキャンバス幅 ≒ 画像上のemサイズpx。実際の出力寸法が異なる場合は再計算。参照pxとptを混ぜない
固定領域：選択したページ種別の位置・禁止範囲（本文・表紙・イントロ・エンドの設定を混ぜない）
文字の指定一覧（要素ごとに記入。サイズ範囲のまま渡さない）：
要素ID／正式原稿／位置・最大幅／指定サイズと参照単位／換算px／スライド幅に対する比率／書体・太さ／行数・行間
［顧客の画像用文字設定を読み、上部タイトル・主要数値・説明など、そのページで選んだ実際のサイズと単位を記入］
文字サイズの制約：許容上限が顧客定義にある場合は値と単位を具体的に記入。上限は標準値・目標値ではない。上限未定義の場合は勝手に設定せず、要素ごとの採用サイズを使う。各要素は上記の指定値を使う。余白を埋めるために拡大しない。全要素を一律に太字にしない。
文字入り配置見本：添付した見本に対する相対サイズ・占有幅・行数を維持する。ガイド用の文字・枠・寸法は完成画像へ描かない。
色と部品：色コードと役割／余白・囲み・矢印・装飾の指定
情報量：選択した段階（ビジュアル優先／中程度の情報量／詳細／超詳細）と、このページでの図・説明・根拠・注記の配分
出典・ページ番号：画像に含めるか、後で追加するために空けるか

構図見本：ID・版・PNG・受け継ぐ配置と主従／個別設計の場合は理由
顧客見本：色・書体・固定領域／構図見本との役割の違い
実際に添付する画像・素材：
［テンプレート／文字入り配置見本／写真・図など、各ファイルと役割・使う場所・参照する特徴］
生成後に直接配置・合成する要素：正式ロゴ／輪郭・遮蔽を保持するSVGなど。位置と空ける領域も指定
文字入り配置見本も実際に添付する。ファイル名を書くだけで添付済みと扱わない。
参考画像の文章は原稿に流用しない。配置ガイドの枠・ID・座標・説明は描かない。

修正時のみ：変更する箇所／それ以外で維持する内容・配置
必須条件：原稿と関係を無断で削除・追加しない。今回のデザイン設定を守る。
```

生成前に空欄を埋め、不要な項目は削除します。画像生成の詳細な判断は[画像生成章](generation.md)に従います。下の出力記録は生成ツールへ送りません。

### 画像の出力・採用記録

```
案件情報・構成記録：参照先
対象ページ：
生成指示の保存先・版：
使用したツール／実際に渡した参照画像・素材：
出力画像：ファイル・版／実際の幅・高さpx
直接利用・合成した素材：原本・派生素材／配置と合成後のファイル
図解の確認：図だけで伝わる関係／見本から残した特徴／実添付ファイルとの対応／残る差分
原稿・配置・デザインの確認結果：不具合／修正箇所／再確認結果
文字サイズの確認：文字入り配置見本のファイル／実際の画像幅による換算値／タイトル・主要数値・本文の相対サイズ・占有幅・行数・太さ／残る差分・修正結果（厳密なpt値の検証とは区別）
提示した画像：ファイル・版
採用状況：未確認／修正依頼／採用／画像のみ完了
採用・進行指示：該当するユーザー発言または事前の明示指示
引き継ぐ正しい原稿・必須条件：参照先
未解決事項：
```
