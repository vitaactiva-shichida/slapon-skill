# 構成の記録ひな型

原稿の転記ではなく、配置先と関係を記録します。ページごとに作成し、図解を使わない場合は接続欄を省けます。

```
ページ構成：役割、基本枠のID／本文の部品構成／個別設計（選択理由・省略理由を記録）
選択理由・適用する個別設定：
情報量：案件の基本値／このページのみ変更する場合の指定
案件情報：参照先
対象ページ・構成の版：
読み手の問い：
主メッセージ・タイトル案：
根拠：原稿の位置・項目ID／支える主張
解釈・提案・留保：該当する場合のみ／原稿にあるものか新規提案か
前後ページとのつながり：本編が複数ページの場合
図解の型：情報の関係／選んだ理由（見本IDは下欄）
ページ配置：型IDまたは配置方針
見本検索：検索条件・検討ID・採否理由／再選定省略の理由
採用したデザイン見本：ID・版／該当なしの理由
構図から受け継ぐ特徴：配置・主従・余白・接続／原稿に合わせる変更点
図だけで伝える関係：短いラベルと配置から何が分かるか
前後ページとの構図比較：反復する理由／主張に応じて変える点
参照画像：選択したPNG／生成時に実際に添付したファイル
読み順：

掲載内容の対応表（必要な行を追加）
原稿の位置・項目ID → 領域・要素ID → 掲載方法
例の記入形式：段落／表の行など → 領域ID → 本文／図／表／注記
※全文の写しは不要。保持する数値・条件・出典も配置先を対応させる。

接続（ある場合）：始点ID → 終点ID／意味／根拠となる原稿位置
関係の限定：仮説・予定など、原稿にある条件と表示箇所
変更点：元の原稿・指定WFから変える箇所／理由／依頼上の許容範囲
内容確認：欠落・重複・関係・条件を照合した結果／未解決点
```
