## 表の定義

Standard原本の12枚目。比較軸の左列と選択肢の列をそろえ、読み手が横に比較できるようにする。

| 部位 | Standardの扱い |
| --- | --- |
| 列見出し | 通常列sub、注目列comparisonMain＋comparisonText。注目先は原稿で決める |
| 項目列 | subの面＋太字。説明列とは独立した幅 |
| 本文セル | 通常background＋text、注目列は淡色面。説明左揃え、数値右揃え |
| 罫線・角 | 細いlineで行を区切る。太いグリッドや立体的な影は加えない |
| 文字・余白 | 本文24〜26pxを初期提案。比較作例12は表内文字22px・行送り30px、注記16px。左右24px／上下16pxを確保 |
| 行数が多い | 同じ比較軸でページを分割し、表頭を再掲。極小文字へ一律縮小しない |
| PowerPoint | 表構造と文字はネイティブ表。注目列の枠等は別図形でもよい |
