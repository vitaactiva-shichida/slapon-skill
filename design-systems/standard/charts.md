## グラフの定義

Standard原本の10・11枚目を基準にする。サンプルのKPIやグラフ値はダミー。実データ、単位、分母、期間、軸範囲を先に確定する。

| 型 | 配色と表示 | データ・編集 |
| --- | --- | --- |
| C01 / 折れ線 | 主色の線、控えめな点、値を直接表示。最新値は太字。軸は薄く | 折れ線はネイティブグラフ。サンプルの高さから未提供の値を推測しない |
| C02 / 円・構成比 | 主系列main、比較系列accent。円の外に名称と値、細い引出し線 | 分母と合計を確認。項目が多ければ棒へ変更。3D円は使わない |
| C03 / 積上げ棒 | main / series2 / series3で工程等を区別。凡例、系列内数値、合計を対応 | 絶対量はゼロ基準。長さが合計を表す。100%積上げと混同しない |
| KPI | primaryInkの大きい数値と、textのラベル、mutedの比較条件 | 削減率=(元−後)÷元。元が0なら率を算出しない。値と単位を別の文字部品へ |
| 系列文字 | onSeries2/3/4、onmainを実背景に対応 | 短い棒で入らない数値は外へ。文字の省略や補色への変更で解決しない |

グラフデータと系列・軸はPowerPointで編集可能にする。独立ラベル・矢印・KPIは別部品。SVG全体の貼付だけをネイティブ編集可能とは扱わない。
