## 長文・光の背景・代替書体の例外処理

| 条件 | 処理 |
| --- | --- |
| 日本語見出し2行 | 36→34→32、行送り54を目安。下端＋18px以降へ本文を送る。 |
| 本文が多い | 投影向けは12〜14pxを候補に、要約・領域拡大・分割を行う。 |
| 半透明の面 | 背景・重なりの合成色を確認。文字や輪郭をまとめて薄くしない。 |
| ロゴと光が重なる | カラー／白を局所コントラストで選び、両方が弱い場合だけ紙色の下地。 |
| 色を新設 | PNGを色相変更せず、4役割を再制作して文字・ロゴ・図表を確認。 |
| 書体が使えない | 明朝はYu Mincho／Georgia、本文はYu Gothic／Arialを候補に再レイアウト。 |
| 小さい図表 | 800座標と1600座標を混同しない。細線と注記を実寸で確認。 |
