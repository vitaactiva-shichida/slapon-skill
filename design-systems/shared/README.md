# 共通のデザイン原則

diagram-rules.htmlは図解の意味・接続・重なり・透明度の適用単位・編集単位を定義するHTML正本です。CompanyとSerifのデザインシステムから読み込んで、同じ顧客デザイン内へ解決済みのHTML・Markdown・JSONを出力します。

角丸・塗りの透明度・余白密度・影は各テンプレートのstyle-profileで定義します。共通の制作プロセスの正本は引き続きgithub/slapon/です。ここへ制作手順を複製しません。Standardの既存値は同テンプレートのHTMLを参照し、Companyはその考え方を使って固有の造形値を定めています。
