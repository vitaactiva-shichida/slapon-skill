## 長文・狭い図表・半透明・代替書体の扱い

| 条件 | 対応 |
| --- | --- |
| タイトル2行 | タイトル領域を128pxへ増やし、本文を下端＋38px以降へ送る。 |
| 36pxでもタイトルが収まらない | 表現・意味の切れ目・ページ分割を見直す。無断省略しない。 |
| 本文や表の情報が多い | 最大行数から必要高さを計算。カラム・行高・ページ数を調整し、注記サイズへ縮小しない。 |
| 背景と図が競合 | 4背景から選び直す。影や半透明の面を足してごまかさない。 |
| 塗りが半透明 | 面だけへalphaを設定し、背景・重なりの合成色と文字の読みやすさを確認。 |
| 色が非常に明るい | onmainと正式ロゴの版を確認。全体の色置換で白やロゴを改変しない。 |
| 書体が使えない | Yu Gothic / Arialで代替し、実寸の改行・数字幅・はみ出しを再確認。 |

HTMLの定義確認、SVGの画像化、画像生成、PowerPoint再構成、PowerPoint実機の編集確認は別の検証です。機械検証が通ったことだけで、デザイン確認済み・顧客承認済み・納品済みにしません。
