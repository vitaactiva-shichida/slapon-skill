## 10 — 素材と使用範囲

| 素材 | 保持・編集の扱い |
| --- | --- |
| 正式ロゴ | カラー／白版を別ファイルで保持。外側の余白と縦横比を確認し、ロゴの輪郭や指定色を勝手に変更しない。 |
| Companyの背景 | ベクターの輪郭・順番・透明度を固定し、役割に対応する塗り色を交換。必要なら最終サイズで画像を書き出す。 |
| Serifの背景 | 配色×4役割のPNG。再圧縮・引き伸ばし・色相変更を繰り返さず、元の画像を保持する。 |
| 人物写真 | Figma見本の差し替え用。実在顧客の社員とは扱わない。納品時には支給写真・使用条件を確認した写真へ交換する。 |
| フォント | assets/fonts/に書体とOFLを同梱。端末に未導入ならPowerPoint側でも同じ書体を利用できるようにする。 |
| 参照元 | source-manifest.jsonにFigmaノード、既存書き出し、ハッシュを保持。複製後も出典をたどれるようにする。 |
